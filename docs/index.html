开始前，你可能想问。

下载结果以浏览器实际保存为准。
遇到问题时，先查看画廊的处理记录。

为什么有些图片没有出现？

插件读取页面已加载的图片地址。未加载内容、登录限制或特殊页面结构可能导致缺图。回到商品页，等待图片显示后重新获取。

需要申请什么权限？

下载时只请求选中图片源的访问权限，用于读取原图并转换 PNG。画廊会保存在扩展本机存储；图片不会上传到本项目服务器。

所有图片都会转换成 PNG 吗？

支持浏览器能解码的常见图片格式。动态图片保存为静态帧；小于100×100像素、文件过大、来源不支持或读取失败的图片会被跳过并给出原因。

官网示例就是插件运行结果吗？

示例画廊使用三张自有图片，供体验选择和转换流程。它明确标注为“非扩展运行”，不能代替 Chrome 扩展的实际运行截图或电商站点验证。

目前完成了哪些验证？

官网菜单、示例下载和一张京东商品图的PNG保存已实际核验，9组核心检查及安装包校验通过。其他平台、批量处理和异常场景仍需逐项验证；测试范围见GitHub源码说明。
