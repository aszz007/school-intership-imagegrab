04 / BEFORE YOU START

几个实际问题。

所有商品图片都能下载吗？

插件只能提取页面可见或已加载的图片地址。登录限制、图片防盗链、特殊页面结构或未加载图片可能影响结果；失败项会显示原因，可回到页面重新获取。

图片会被上传到服务器吗？

不会。图片在浏览器中提取和转换，画廊数据保存在扩展本机存储。下载时仅向图片原始地址请求文件。

为什么需要确认图片源权限？

商品图片可能来自独立图片域名。开始下载时，只请求选中图片源的访问权限，用于读取原图并转换PNG。
